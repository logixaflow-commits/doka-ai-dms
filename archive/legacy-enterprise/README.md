# Legacy Enterprise Archive

This boundary documents material that is preserved for the later commercial/multi-user edition.

Nothing in this archive is required by the Personal Local runtime.

The legacy enterprise implementation is retained primarily inside `web-platform/backend` and `web-platform/frontend` so its source remains reusable. The legacy FastAPI entry point has been moved here from the active backend root.

Historical documentation is preserved under `docs/legacy/`.
Legacy deployment artifacts are preserved under `infrastructure/`.
